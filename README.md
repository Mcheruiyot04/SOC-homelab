# SOC-homelab

## Overview
This repository documents my hands-on journey in developing a Security Operations Center (SOC) home lab to gain practical experience in cybersecurity, particularly defensive security and security monitoring.

The lab simulates a small enterprise security environment using virtual machines and open-source security tools.

## Lab Objectives
- Understand SOC operations and security monitoring.
- Deploy and configure a Wazuh SIEM platform.
- Monitor Windows endpoint activities using Sysmon.
- Collect, analyze and investigate security events.
- Simulate controlled attacks using Kali Linux.
- Practice threat detection, alert triage and incident investigation.

## Lab Environment

| Component | Technology |
|---|---|
| SIEM | Wazuh |
| Server | Ubuntu Linux |
| Endpoint | Windows 11 |
| Endpoint Telemetry | Sysmon |
| Attacker Machine | Kali Linux |
| Virtualization | VirtualBox |
